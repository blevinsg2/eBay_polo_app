# Data

`brand_sellthrough_snapshot_2026-10.csv` is a one-time snapshot (Oct 2026) of public eBay search result counts for
men's golf polos by brand: roughly how many are listed (active), how many sold recently, and the median sold price.
These are eBay's rounded public counts, not data from any seller account. Keyword matching is loose, so treat it as a
rough "does this brand move?" guide, not gospel. The code doesn't use it; it's here as reference.
